`main.ts` writes a single original line roasting my fridge to `/output/entry.txt` — 182 characters, no setup, no second sentence.

## The line

> My fridge hums all night like it's auditioning for a band, hoards leftovers older than my passwords, and still lets the ice cream melt — the only thing it keeps cold is its attitude.

## Run

```sh
node main.ts
```

Reads nothing from outside the repository and writes only `/output/entry.txt`.
